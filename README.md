# 🏫 Portal Web - U.E. Marista Sagrados Corazones I (Roboré)

Bienvenido al repositorio oficial del sitio web de la **Unidad Educativa Marista Sagrados Corazones I**. Este proyecto es una plataforma informativa y de gestión diseñada para representar la identidad institucional, los valores maristas y facilitar el acceso a la comunidad educativa en Roboré, Bolivia.

---

## 📋 Descripción del Proyecto

El sitio web funciona como el hub digital de la institución (RUE: 61940001). Ofrece una interfaz moderna, responsiva y animada para que padres, estudiantes y docentes puedan conocer la misión del colegio, las últimas noticias y acceder al sistema académico.

### ✨ Características Principales
* **Diseño Moderno y Responsivo:** Optimizado para dispositivos móviles mediante Bootstrap 5.
* **Animaciones Avanzadas:** Uso de la librería AOS (*Animate On Scroll*) para dinamismo visual.
* **Gestión de Contenidos:** Secciones de Misión, Visión, Valores Maristas y Testimonios.
* **Módulo de Noticias:** Feed visual para eventos, talleres y avisos.
* **Estadísticas en Tiempo Real:** Visualización de datos de matrícula y crecimiento institucional.
* **Acceso al Sistema:** Botón de acceso directo al portal de gestión (Login).

---

## 🛠️ Tecnologías Utilizadas

El proyecto utiliza un stack frontend de alto rendimiento:

* **HTML5 & CSS3:** Estructura y estilos personalizados.
* **Bootstrap 5:** Framework de componentes para diseño responsivo.
* **JavaScript (ES6+):** Lógica interactiva y carga de animaciones.
* **Font Awesome 6:** Iconografía profesional.
* **AOS Library:** Efectos de desplazamiento (Scroll animations).
* **Google Fonts:** Tipografía *Montserrat* y *Open Sans*.
